Another highly-requested block set and Frost Walker Sulfur Cubes.

## Snow Bricks

Snow Brick variants have **0.6 hardness** and **0.6 blast resistance**.

Snow Bricks show up as {::colordef:#FFFFFF} "Snow" on a map.

## Cold Sulfur Cube Archetype

The cold Sulfur Cube archetype functions identically to Frost Walker I, except that Sulfur Cubes can also freeze flowing water, which turns into source blocks after melting. A Sulfur Cube only creates Frosted Ice when **sliding along the ground**. If a Sulfur Cube falls into water, it will not create Frosted Ice.

## Misc

In previous versions, entities falling through lava would only reduce their fall distance once every tick.

## Data Packs

### Tags

{::bug:MC-312632} was fixed by adding `sulfur_spike` and `icicle` to the `#dangerous_for_teleportation` block tag individually, rather than using the `#speleothems` block tag.

The `#flying` and `#swimming` entity type tags are unused.

The `#swimmable` fluid tag defines which fluids the player can freely swim in, by pressing forward while in the liquid.

## JVM Args

Replaced `-Xms2G -Xmx4G` with `-XX:ErgoHeapSizeLimit=4G -XX:MaxRAMPercentage=25` by default.
