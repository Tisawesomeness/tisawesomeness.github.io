The first 26.4 pre-release is out with mainly bugfixes.

## Mobs

Frostbites with Ice Balls will now move towards the player until they are within their 16 block throwing range.

Mobs can no longer use the Frost Walker enchantment when `mob_griefing` is false. Armor Stands can still use Frost Walker as normal.

## Friend List

Outgoing presence status is now sent every 5 minutes, or earlier if your status changes, with a 5-second minimum delay between updates. Presence status is no longer sent faster when the friends list is open.

## Data Packs

### Enchantment Effects

Mobs using the `replace_disk` enchantment effect no longer replaces any blocks if the `mob_griefing` game rule is false, fixing {::bug:MC-313298}. `replace_block` still works when `mob_griefing` is false.

## Command-Line Args

The client no longer connects to the signaling server from friend and presence updates if `--offlineDeveloperMode` is set.

## Mojang API

The client will send all headers defined in the `MINECRAFT_API_HEADERS` environment variable in all requests. Headers are defined by `key=value` and separated by commas.

## Signaling Protocol

### Friend List Updated

The signaling service will send the client a message over the signaling websocket when the user's friend list is updated.

#### Incoming Message

- `jsonrpc`: `2.0`
- `id`: The numeric transaction ID as a string, incremented with each request
- `method`: `Java_PresenceUpdated_v1_0`
- `params`: Object, or list of objects (only the first is parsed)
    - `profileId`: The player’s in-game UUID, without dashes
    - `name`: The player's in-game username
    - `updateType`: One of `ADD`, `REMOVE`, `ACCEPT`, `REJECT`

```json
{
  "jsonrpc": "2.0",
  "id": "1",
  "method": "Java_FriendsUpdated_v1_0",
  "params": {
    "profileId": "f6489b797a9f49e2980e265a05dbc3af",
    "name": "Tis_awesomeness",
    "updateType": "ADD"
  }
}
```

#### Acknowledgement

- `jsonrpc`: `2.0`
- `id`: The friend list update transaction ID as a string
- `result`: Empty object

```json
{
  "jsonrpc": "2.0",
  "id": "1",
  "result": {}
}
```
