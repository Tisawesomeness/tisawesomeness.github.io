This snapshot adds jukebox playlists, brittle ice, and several technical changes to sounds and fluids.

## Jukebox Playlists

A jukebox in playlist mode saves the chest slot it last took a disc from. Even if the discs are moved around, or the chest is broken and placed again, the jukebox will play the next disc starting from the saved slot.

## Brittle Ice

Brittle Ice has **0.5 hardness**, **0.5 blast resistance**, and **0.98 friction** (same as Packed Ice and Frosted Ice).

The best tool for Brittle Ice is a pickaxe. It breaks when pushed by a piston and cannot be pulled.

Brittle Ice shows up as {::colordef:#A0A0FF} "Ice" on a map. When placed under a note block, they make the "Chime" instrument sound.

Players, mobs, armor stands, and mannequins crack Brittle Ice when stepping on it directly. Riding a vehicle such as a boat will not crack the ice.

Brittle Ice generates fully intact, cracks in three stages, then breaks completely. After each stage, the block schedules a tick 24 ticks in the future and will not crack until 24 ticks pass.

Once a Brittle Ice block breaks completely, neighboring Brittle Ice blocks crack by one stage. If a neighboring block breaks completely, it does not cause a chain reaction.

Brittle Ice formed by water horizontally bordering Blue Ice will not crack for 24 ticks.

## Ice Caves

Ice Caves can now generate mineshafts.

## Misc

Players can no longer click on portals in the Debug mode world to teleport to another dimension.

## Data Packs

### Block States

#### Jukebox

| Name            | Default | Data Type | Description                             |
| --------------- | ------- | --------- | --------------------------------------- |
| `playlist_mode` | `false` | Boolean   | True if the jukebox is in playlist mode |

#### Brittle Ice

| Name  | Default | Data Type | Description                                        |
| ----- | ------- | --------- | -------------------------------------------------- |
| `age` | 0       | 0-3       | Starts at 0, increases by 1 for each melting stage |

### Block Entities

#### Jukebox

- Integer `playlist_position` - Slot ID of the last disc taken or swapped from the container, optional

### Entity Data

Fixed several bugs where sounds would play even if `Silent` was true.

### Tags

#### Block Tags

Added the `#ice_crevasse_replaceables` block tag.

Jukeboxes can retrieve discs from the following containers when added to the `#jukebox_containers` block tag, though the "Playing Next" tooltip will not display:

- Barrel
- Furnace
- Blast Furnace
- Smoker
- Brewing Stand
- Chiseled Bookshelf
- Crafter
- Decorated Pot
- Dispenser
- Dropper
- Hopper
- Jukebox
- Shelf
- Shulker Box

#### Damage Type Tags

Added the `#no_hurt_sound` damage type tag.

#### Item Tags

The `#jukebox_containers` block tag has a corresponding item tag.

## Network Protocol

The server will disconnect the client if server code threw an exception while processing a client packet.

## Debug Properties

Removed `-DMC_DEBUG_SUBTITLES`.
