Surface sulfur caves and several small improvements.

## Blocks

Beds now restitute 75% of a bounce, up from 66%.

## Peer-to-Peer Protocol

[Interactive Connectivity Establishment](https://datatracker.ietf.org/doc/html/rfc8445) (ICE) can now be negotiated over TCP.

The `ICE_CANDIDATE` signaling message format has changed from:

```json
{
  "type": "ICE_CANDIDATE",
  "sessionId": "87c025a5-8ab5-4c07-8188-2057dabf7ed1",
  "iceCandidate": {
    "candidate": "candidate:842163049 1 udp 2122260223 192.0.2.1 49152 typ host",
    "sdpMid": "0",
    "sdpMLineIndex": 0
  }
}
```

to:

```json
{
  "type": "ICE_CANDIDATE",
  "sessionId": "87c025a5-8ab5-4c07-8188-2057dabf7ed1",
  "candidate": "candidate:842163049 1 udp 2122260223 192.0.2.1 49152 typ host",
  "sdpMid": "0",
  "sdpMLineIndex": 0
}
```
