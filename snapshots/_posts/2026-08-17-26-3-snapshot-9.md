An early snapshot with more tweaks and a highly anticipated bugfix.

## Redstone

To fix [MC-310372](https://bugs.mojang.com/browse/MC/issues/MC-310372), tripwires now create a scheduled tick with a 1 tick delay instead of a 0 tick delay, placing the scheduled tick correctly in the chunk's tick queue. However, the spurious player movements that caused [MC-305475](https://bugs.mojang.com/browse/MC/issues/MC-305475) are still present.

## Data Packs

### Number Providers

Added new number providers:

| Number Provider                       | Value |
| ------------------------------------- | ----- |
| `cooking/normal_speed_multiplier`     | 1     |
| `cooking/normal_burn_time_multiplier` | 1     |
| `cooking/fast_speed_multiplier`       | 2     |
| `cooking/fast_burn_time_multiplier`   | 0.5   |

Cooking number providers now reference these new number providers.
