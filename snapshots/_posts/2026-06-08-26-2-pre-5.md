Bugfixes and a fix to hardcore cheating (which can still be bypassed by editing the world file as always)

## Changes

As the host of a world, changing the game mode with F3 + F4 or with commands now changes the default game mode of the world **in the singleplayer world select screen**. This does **not** change the game mode for other players (at least, it is [not supposed to](https://bugs.mojang.com/browse/MC/issues/MC-308699)).
