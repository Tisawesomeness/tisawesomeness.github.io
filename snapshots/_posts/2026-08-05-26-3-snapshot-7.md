### Chest Loot

Each regular chest additionally contains an Abandoned Camp explorer map in one of the following biomes (excluding the biome the chest is in):
- Bamboo Jungle
- Cherry Grove
- Birch Forest
- Dappled Forest
- Flower Forest
- Pale Garden
- Swamp
- Windswept Forest

### Secret Chest Loot

Each secret chest additionally contains an explorer map for one of the following structures:
- Ancient City
- Trial Chambers
- Mineshaft
- Desert Pyramid
- Jungle Pyramid
- Warm Ocean Ruins
- Woodland Mansion

## Cushions

Cushions can no longer be placed in positions where the cushion's entire hitbox is encased within blocks (not just full blocks). If a cushion becomes entirely encased within blocks, it will eventually pop off. These changes fix [MC-309797](https://bugs.mojang.com/browse/MC-309797).
