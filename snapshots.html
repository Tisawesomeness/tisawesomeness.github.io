Minecraft Snapshot Reverse Engineering

This is where I post my findings from decompiling the source code for every new Minecraft snapshot. I document the exact details of how each feature works, and everything not found in the official changelogs.

What's Included:

  • Additional details for new features
  • Undocumented gameplay changes
  • Undocumented bug fixes
  • Data pack changes
  • Command-line arguments
  • Mojang API changes

Not Included:

  • Realms
  • Rendering changes
  • Probable bugs and regressions
  • Networking protocol
  • Changes that only affect mods
  • Private security vulnerabilities

These writeups assume you have read the snapshot's changelog and bug report list. You can usually expect a post within a few days after release.
