This website uses [Ackee](https://github.com/electerious/Ackee/) for pageview counting and analytics. Ackee does not collect personally identifiable information (PII). Ackee processes the following data:

- Date and time of visit
- URL of the page being visited
- URL of the page that was viewed prior to the current page
- Screen resolution
- Main language of the browser
- User agent of the browser
- Device name and manufacturer

Analytics data is only stored in aggregate and cannot be linked to a specific user.

Ackee creates a hash of the IP address, user agent, and a random salt that changes daily to ensure page views are not counted twice. The IP address is never stored.
